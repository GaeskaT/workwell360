> • Daily check-in that recommends the right resource — no diagnosis
> • "What do you need today?" pathways for anger, stress, burnout, grief, work & relationships

> • Diaries, breathing & grounding exercises, trigger maps, boundary and self-care tools
> • Verified counsellor directory with in-app session requests
> • Confidential anonymous workplace reporting
> • Self-care store: journals, courses and workbooks

## Compliance notes (fill these in Play Console)

**Data safety form**
- Data collected: *None leaves the device by default.* All wellbeing data (check-ins, journals,
  assessments) is stored locally via the browser. If/when you add a backend or payments, update
  this section.
- Data shared with third parties: None (in v1).
- Is data encrypted in transit: Yes (HTTPS).
- Can users request deletion: Yes — Settings → "Erase all my data".

**Content rating:** Complete the questionnaire. Expect **Everyone / PEGI 3**, but declare that the
app references mental-health, substance-use and crisis topics.

**Health apps declaration:** Declare it is a **wellbeing / self-help** app that does **not** provide
medical diagnosis. The in-app crisis screen and "not a diagnosis" disclaimers support this.

**Sensitive content:** Because the app addresses self-harm/crisis, include the crisis-support screen
(already built at `#/crisis`) and keep local-hotline numbers accurate for each market before launch.
